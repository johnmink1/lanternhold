# Lanternhold

Lanternhold is a free idle dungeon crawler from Born 2 Game, LLC.

Play it at https://lanternhold.born2gamellc.com

This repository only publishes the game. The source lives in `johnmink1/pricing-tools` under `lanternhold/`, and the workflow in `.github/workflows/deploy.yml` copies it here every 10 minutes when it changes.
